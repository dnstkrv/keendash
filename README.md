# keendash

Карточка «Сервисы» на главной странице веб-интерфейса Keenetic (NDMS) для сервисов, установленных через Entware, и
отдельная страница-дашборд для них и для сервисов в домашней сети.

<img src="docs/card.png" width="560" alt="Карточка «Сервисы»: статусы сервисов, вкладка AWG с туннелями и графиками">

- статус всех сервисов Entware и ссылки на их веб-страницы (порты определяются сами);
- вкладки с подробностями и графиками для поддерживаемых сервисов, вкладка видна, только если сервис установлен;
- больше 35 сторонних сервисов (медиа, умный дом, серверы, сеть, файлы): добавляются в окне настроек, в том числе
  через поиск в локальной сети;
- страница «Дашборд» (пункт в меню под «Системным монитором»): все карточки сразу, группы, ширина, сворачивание;
- проверка новой версии и обновление кнопкой на карточке.

Работает на любых Keenetic с Entware.

## Установка

Узнайте архитектуру Entware (`opkg print-architecture`: `aarch64-3.10`, `mipsel-3.4` или `mips-3.4`), добавьте фид и установите пакет:

```sh
echo "src/gz keendash https://dnstkrv.github.io/keendash/aarch64-3.10" > /opt/etc/opkg/keendash.conf
opkg update && opkg install keendash
```

Других пакетов не нужно. После установки обновите страницу роутера (Ctrl+F5). Обновление: кнопкой на карточке или `opkg update && opkg upgrade keendash`.

## Настройка

### Сторонние сервисы

Сервисы добавляют, правят и удаляют в окне «Настройки» на странице «Дашборд»; один тип можно добавить несколько раз.
Кнопка «Сканировать сеть» ищет сервисы сама: роутер проверяет устройства в сети на стандартных портах и узнаёт сервис
по ответу (пароли при этом никуда не отправляются). Найденное отмечают галочками и добавляют, остаётся вписать ключ,
если сервис его требует, и нажать «Сохранить». Данные появятся в течение минуты.

Если сервис стоит на самом роутере, можно указать `http://127.0.0.1:порт`. Сервис, добавленный по имени хоста, поиск
может предложить ещё раз по IP-адресу. Переименованные Overseerr и Jellyseerr, Forgejo и Gitea со своим названием поиск
не узнаёт — их добавляют вручную.

<details>
<summary>Где взять ключи</summary>

- Sonarr, Radarr, Prowlarr, Lidarr, Overseerr, Jellyseerr: Settings → General → API Key; Bazarr: Settings → Security;
  Tautulli: Settings → Web Interface; SABnzbd: Config → General;
- Jellyfin: Панель управления → API-ключи; Immich: Настройки аккаунта → API-ключи (право `server.statistics`);
- Plex: токен из адреса страницы «View XML» у любого фильма ([инструкция Plex](https://support.plex.tv/articles/204059436-finding-an-authentication-token-x-plex-token/));
- Home Assistant: Профиль → Безопасность → Долгосрочные токены; Grafana: Administration → Service accounts, роль Viewer;
- Uptime Kuma: Settings → API Keys; Portainer: My account → Access tokens; TrueNAS: Credentials → API Keys (только по https);
- Proxmox: Datacenter → Permissions → API Tokens, роль PVEAuditor; в «Логин» ID токена (`root@pam!keendash`), в «API-ключ» секрет;
- Pi-hole: пароль веб-интерфейса или пароль приложения; NextDNS: в «Логин» ID профиля, API-ключ на странице Account;
- Speedtest Tracker: Settings → API Tokens (`results:read`); Nginx Proxy Manager: лучше пользователь только с просмотром;
- Nextcloud: токен serverinfo (Настройки → Система) или логин администратора и пароль приложения; Syncthing: Действия → Настройки → Общие;
- Paperless-ngx: профиль → API Auth Token; Gitea / Forgejo: Настройки → Приложения, права read на repository, issue, notification.

Логин и пароль не нужны там, где сервис пускает роутер без них. Сертификат Proxmox, Frigate, TrueNAS и Syncthing не
проверяется (он обычно самоподписанный); для остальных с самоподписанным сертификатом используйте http-адрес.

</details>

**Frigate: кадры с камер.** Настройка «Кадры с камер» показывает под каждой камерой кадр, обновляемый раз в минуту. Кадры
хранятся только в памяти роутера и видны, когда веб-интерфейс открыт по https.

**Доступность сайтов.** До 20 доменов или адресов через пробел, проверка раз в 1–60 минут. Доступным считается любой
ответ сервера; история за сутки сбрасывается при перезагрузке роутера.

**Свой API.** Любой адрес с JSON. В «Что показывать» через `;` до 8 пар `Подпись=путь[:формат]`, например
`Задачи=queue.total; Скорость=speed:bs`. Форматы: `n` число, `b` байты, `bs` байты в секунду, `bit` биты в секунду,
`p` проценты, `s` секунды; без формата — текст.

### Страница «Дашборд»

- карточки перетаскиваются за «⋮⋮» и встают вплотную под ту, что выше в колонке;
- «⋯» — ширина 1/3, 2/3 или 3/3, «▾» — свернуть, «⚙» — настройки этого сервиса;
- «Новая группа» объединяет карточки, группу можно переименовать, свернуть и разгруппировать;
- раскладка хранится на роутере и одинакова во всех браузерах; на узком экране карточки идут в одну колонку;
- в окне настроек каждую карточку можно скрыть отдельно на странице и на главной.

### Файл настроек

`/opt/etc/keendash/keendash.conf`:

```sh
PORT=8189          # порт веб-сервера карточки
LAN_IFACE="br0"    # интерфейс, на адресе которого он слушает
LAN_IP=""          # или явный адрес
GEO=1              # страны у адресов Antiscan (0 = выключить)
LINKS="            # свои ссылки на веб-страницы сервисов
firc=666
telemt=hide
"
```

`LINKS`: `имя=порт`, `имя=http://хост/путь`, `имя=-` (без ссылки), `имя=hide` (скрыть сервис). После правки:
`/opt/etc/init.d/S81keendash restart`.

## Безопасность

- Настройки сервисов, включая пароли и ключи, лежат в `/opt`: любой, кто вошёл в веб-интерфейс роутера, может прочитать
  их через файловый менеджер прошивки. Давайте сервисам ключи с минимальными правами.
- Страны в Antiscan определяются через ip-api.com по http: заблокированные адреса уходят в сторонний сервис. Отключить:
  `GEO=0`.
- По https (в том числе через KeenDNS) карточка берёт данные через сам веб-интерфейс роутера, новых портов не открывается.

## Ограничения

- Ссылки «Открыть» ведут на адрес роутера в локальной сети и из интернета обычно не откроются.

## Удаление

`opkg remove keendash`
